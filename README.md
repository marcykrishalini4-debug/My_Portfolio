# Marcy Krishalini — Portfolio Website

## Run the website
1. Extract the ZIP folder.
2. Open the extracted `Marcy_Professional_Portfolio` folder in VS Code.
3. Open `index.html`.
4. If Live Server is installed, right-click `index.html` and select **Open with Live Server**. Otherwise, double-click `index.html` to preview it in your browser.

## Add your profile photo
- Choose a professional photo.
- Copy it into the `assets` folder.
- Rename it exactly to `profile.jpg`.
- The image area on the home page will display it automatically.

## Add your GitHub and LinkedIn profile URLs
- Open `script.js`.
- Replace `YOUR-GITHUB-USERNAME` with your GitHub profile URL.
- Replace `YOUR-LINKEDIN-PROFILE` with your LinkedIn profile URL.
- Save the file and refresh the browser.

## Optional updates before publishing
- Confirm that the language proficiency levels you want to publish are accurate.
- Add a Behance or Figma prototype link for FocusSync if you want visitors to view it.
- Update the QuickFix project paragraph to specify your exact individual contribution.
- Add a CV download link once your final CV PDF is ready.

## Files
- `index.html` — page content
- `style.css` — layout, colors and responsive design
- `script.js` — profile links and mobile navigation
- `assets/profile.jpg` — your profile photo goes here
